# PrepStack - Product Requirements Document (MVP)
# Tech stack
Frontend  : React + TypeScript + Tailwind
Backend   : Node.js + Express
Database  : PostgreSQL
ORM       : Prisma
Auth      : JWT

## Product Name

PrepStack

## Target Users

Developers preparing for technical interviews.

## Main Goal

Help developers prepare for technical interviews and track their learning progress.

## Core Features (MVP)

### Authentication

* User can sign up
* User can log in
* User can log out

### Question Bank

* Browse interview questions by topic

  * JavaScript
  * React
  * TypeScript
  * HTML
  * CSS
  * Frontend System Design
  * DSA
* Search questions
* Bookmark questions

### Notes

* Create notes
* Edit notes
* Delete notes

### Progress Tracking

* Mark questions as completed
* Track progress by topic
* Track overall completion percentage

### Dashboard

* View bookmarked questions
* View completed questions
* View progress summary

### Code Playground

* Write code
* Execute code
* Save code solutions

## Future Features (V2)

### AI Assistant

* Ask doubts related to interview topics
* Get explanations
* Generate interview questions
* Review answers

### Analytics

* Weekly learning statistics
* Topic-wise performance analysis
* Learning streaks

### Reminders & Notifications

* Study reminders
* Daily goals
* Progress notifications
